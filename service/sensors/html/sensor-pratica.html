Laboratório Prático com Sensores

Desafios de Bancada | Integração Hardware & Software

A teoria do sensoriamento ganha vida na bancada. Nesta seção prática, apresentamos desafios reais desenvolvidos e testados com microcontroladores, demonstrando a captura de variáveis físicas, o condicionamento de sinais e a resposta automatizada do sistema.

Metodologia Aplicada: Leitura contínua dos sensores → Processamento de limiares no microcontrolador → Acionamento de indicadores e atuadores em tempo real.

Desafio Prático 01

Leitura e Monitoramento de Variáveis Físicas

Arduino UNO Sensoriamento em Tempo Real Monitor Serial Sinalização Visual

Demonstração do circuito de bancada realizando a leitura contínua de sinais emitidos pelo sensor. O microcontrolador amostra os valores analógicos/digitais, realiza a conversão e sinaliza o estado operacional instantaneamente.

Código de Base - Leitura de Sensor (Arduino / C++)
// Desafio 01 - Leitura e Monitoramento de Sensor
const int SENSOR_PIN = A0;
const int LED_INDICADOR = 13;
int valorSensor = 0;

void setup() {
    Serial.begin(9600);
    pinMode(LED_INDICADOR, OUTPUT);
    pinMode(SENSOR_PIN, INPUT);
    Serial.println(">>> Desafio 01 Inicializado - Lendo Sensor...");
}

void loop() {
    valorSensor = analogRead(SENSOR_PIN);
    Serial.print("Leitura Atual do Sensor: ");
    Serial.println(valorSensor);

    if (valorSensor > 500) {
        digitalWrite(LED_INDICADOR, HIGH);
    } else {
        digitalWrite(LED_INDICADOR, LOW);
    }
    delay(100);
}
Desafio Prático 02

Controle de Limiares e Resposta Automatizada

Controle com Histerese Atuadores Automação de Bancada Tratamento de Ruído

Neste experimento, o sistema avalia faixas de operação e limiares críticos. Ao detectar variações bruscas na grandeza física, o microcontrolador aciona automaticamente o elemento de resposta, prevenindo falsos positivos por meio de temporização.

Código de Base - Lógica de Decisão e Histerese (Arduino / C++)
// Desafio 02 - Controle Automático com Faixa de Segurança
const int PINO_SENSOR = A1;
const int ATUADOR_PIN = 8;
const int LIMIAR_SUPERIOR = 650;
const int LIMIAR_INFERIOR = 450;
bool estadoAtivo = false;

void setup() {
    Serial.begin(9600);
    pinMode(ATUADOR_PIN, OUTPUT);
}

void loop() {
    int leitura = analogRead(PINO_SENSOR);

    // Controle com histerese para evitar oscilações
    if (leitura >= LIMIAR_SUPERIOR && !estadoAtivo) {
        estadoAtivo = true;
        digitalWrite(ATUADOR_PIN, HIGH);
        Serial.println("[ALERTA] Limiar atingido - Atuador ACIONADO!");
    } else if (leitura <= LIMIAR_INFERIOR && estadoAtivo) {
        estadoAtivo = false;
        digitalWrite(ATUADOR_PIN, LOW);
        Serial.println("[INFO] Retorno ao normal - Atuador DESLIGADO.");
    }
    delay(150);
}
Desafio Prático 03

Sistema Multissensorial Integrado e Alertas Críticos

Integração Multissensor Sistemas Embarcados Indústria 4.0 / IoT Lógica Combinada

Apresentação do desafio mais avançado: integração de múltiplos pontos de sensoriamento sincronizados. O firmware processa simultaneamente diferentes tipos de estímulos do ambiente e gera alertas em cascata conforme a gravidade das leituras.

Código de Base - Sistema Integrado Multissensor (Arduino / C++)
// Desafio 03 - Sistema Multissensorial com Alertas
const int SENSOR_DIGITAL = 2;
const int SENSOR_ANALOGICO = A2;
const int BUZZER_PIN = 9;
const int LED_STATUS = 12;

void setup() {
    Serial.begin(9600);
    pinMode(SENSOR_DIGITAL, INPUT_PULLUP);
    pinMode(BUZZER_PIN, OUTPUT);
    pinMode(LED_STATUS, OUTPUT);
    Serial.println(">>> Sistema Multissensorial Operante <<<");
}

void loop() {
    int presenca = digitalRead(SENSOR_DIGITAL);
    int nivelSinal = analogRead(SENSOR_ANALOGICO);

    // Avaliação de condições combinadas
    if (presenca == LOW || nivelSinal > 750) {
        digitalWrite(LED_STATUS, HIGH);
        tone(BUZZER_PIN, 1000, 200);
        Serial.print("[CRÍTICO] Evento detectado! Nível: ");
        Serial.println(nivelSinal);
    } else {
        digitalWrite(LED_STATUS, LOW);
        noTone(BUZZER_PIN);
    }
    delay(200);
}

Boas Práticas no Laboratório

Filtragem de Ruído Utilize capacitores de desacoplamento e médias móveis no código para estabilizar sinais analógicos.
Resistores de Pull-up/down Evite pinos flutuantes em sensores digitais garantindo níveis lógicos bem definidos (HIGH/LOW).
Compatibilidade de Tensão Respeite as tensões de operação (3.3V vs 5V) usando divisores de tensão ou conversores de nível lógico.
Calibração em Bancada Compare leituras brutas com grandezas reais conhecidas para ajustar as curvas de calibração do sensor.
